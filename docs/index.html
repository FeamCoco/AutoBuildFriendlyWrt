AutoBuildFriendlyWrt · 点选参数 → 勾选插件 → 一键触发 GitHub Actions

GitHub 仓库 Fork Actions Releases 教程文档

① 连接 GitHub Connect

触发编译需要填写具有 Actions: Read and write 权限的 Personal Access Token， 且仅仓库所有者可触发（工作流在服务端强制校验）。 其他人请 Fork 本仓库搭建自己的页面，教程见 README。

② 构建参数 Build config

③ 剔除官方预装插件 Remove preinstalled

勾选要整组剔除的官方预装插件（luci 前端 + 后端守护进程 + 中文语言包）， 列表实时读取仓库中的 scripts/package_groups.txt，在该文件里新增组别名后本页会自动同步。

④ 追加知名插件 Add plugins

精选 FriendlyWrt 官方源码内的知名插件，勾选即集成进固件。若插件在所选版本的源中不存在，构建日志会提示 [WARN] 并跳过，不影响编译。

⚠️ OpenClash、PassWall、SSR-Plus 等第三方插件不在官方源码内，无法通过本页添加；更多官方源插件可在第 ⑤ 步自定义清单中直接填写包名。

⑤ 自定义清单（可选） Raw packages

直接填写软件包增删清单，空格或逗号分隔，语法与工作流 packages 参数完全一致： -组别名 / -包名 剔除，+包名 追加（无前缀视为追加），可与上方勾选叠加。

⑥ 触发编译 Trigger build
